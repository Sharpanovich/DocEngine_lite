# DocEngine Enterprise (.NET Standalone)

Автономный корпоративный офисный конвертер и процессор документов (Word DOCX, PDF, Excel XLSX).
Разработан на чистом C# (.NET Framework 4.8) специально для работы в закрытых корпоративных средах без Python, без прав администратора и без сторонних библиотек.

---

## 🚀 Установка и запуск в 1 клик

1. Скачайте репозиторий (**Code** ➔ **Download ZIP**).
2. Распакуйте архив в любую папку на вашем компьютере.
3. Запустите файл:
   ```cmd
   СБОРКА_И_УСТАНОВКА.bat
   ```
4. Системный компилятор Windows (`csc.exe`) за 2–3 секунды скомпилирует готовые программы:
   - **`DocEngine Enterprise.exe`** — Главная программа конвертации и работы с документами
   - **`Генератор Лицензий.exe`** — Утилита генерации ключей активации
   - **`Сборка Программы.exe`** — Графический мастер сборки
   - **`Загрузка на GitHub.exe`** — Утилита синхронизации проекта
5. Запустите **`DocEngine Enterprise.exe`** (или **`Запустить Конвертер.bat`**).
6. Для выноса ярлыка на Рабочий стол запустите **`Создать ярлык на Рабочем столе.bat`**.
